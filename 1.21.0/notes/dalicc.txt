# DALICC Research Collection

DALICC = Data Licenses Clearance Center. A framework and tooling for
formal, machine-readable license representation and automated license
compatibility checking, with a focus on data (not just code). Developed
primarily at WU Vienna and Semantic Web Company.

This file collects entry points: known URLs (high confidence) and search
queries you can run yourself to surface papers, slides, and code.

================================================================================
SUGGESTED READING ORDER
================================================================================

1. Start with https://www.dalicc.net/ — read the project description and
   walk through the license composer demo with a few examples
   (e.g., CC-BY + CC-BY-SA, CC-BY-SA + CC-BY-NC-SA).

2. Use the search queries under "KEY PAPERS AND TALKS" to find the
   foundational paper(s). Look for one published around 2018-2020 that
   introduces the framework.

3. Then read comparison material to position DALICC against OSADL and
   FOSSology, since those are the alternatives you may end up using
   for code-side licenses.

4. Finally, dig into ODRL — DALICC builds on top of it, and any future
   work you do in this area will benefit from understanding ODRL
   directly.
