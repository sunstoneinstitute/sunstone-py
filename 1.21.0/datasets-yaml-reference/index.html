    datasets.yaml key reference¶

    Generated by scripts/gen_schemas.py from src/sunstone/vocab/. Do not edit by hand.

    Every key is one of: a Data Package 2.0 property (dp) for its level, a sunstone config key (config), a JSON-LD keyword (jsonld), or an RDF property (rdf: prefix:local or an absolute IRI). RDF properties are allowed at every level; the rows marked rdf below are the ones a rule asks for. Rule levels follow RFC 2119 (MUST, SHOULD, MAY).

    Editor support: add # yaml-language-server: $schema=https://sunstoneinstitute.github.io/sunstone-py/schemas/datasets.schema.json as the first line of datasets.yaml.

    Agents and identifiers¶

    Agent objects (dct:publisher, each dct:creator entry) carry rdfs:label (full name), optional skos:altLabel (short name) and optional "@id" (IRI). Repeat an agent within one file with a YAML anchor: dct:publisher: &fao {rdfs:label: ..., skos:altLabel: FAO} on first use, dct:publisher: *fao after. Anchors do not cross include files.

    A source with a DOI puts it in "@id": "@id": https://doi.org/10.1016/j.aqrep.2022.101316.

    Source¶

    Path: inputs.source

    Key Class Rule Description Example

    dcat:downloadURL rdf MUST (one of) The URL of the downloadable file in a given format. E.g. CSV file or RDF file. The format is indicated by the distribution's dcterms:format and/or dcat:mediaType. dcat:downloadURL: https://example.org/data.csv
    dcat:landingPage rdf MUST (one of) A Web page that can be navigated to in a Web browser to gain access to the catalog, a dataset, its distributions and/or additional information. dcat:landingPage: https://example.org/about

    Complete example¶

    min_sunstone_version: 1.20.0
dcat-si:methodology: METHODOLOGY.md
inputs:
  - name: fish-farms
    title: Fish Farms
    description: Salmon farms by site.
    path: inputs/fish_farms.csv
    prov:generatedAtTime: '2026-01-02'
    prov:wasGeneratedBy: {dct:type: manual-download}
    source:
      "@id": https://doi.org/10.1016/j.aqrep.2022.101316
      title: Salmon farm survey
      dct:publisher: &pub
        rdfs:label: Elsevier
        skos:altLabel: ELS
      dct:creator:
        - rdfs:label: 'Aas, T. S.'
      dct:issued: '2022'
      dct:modified: '2022-06-01'
      dct:isPartOf: {rdfs:label: 'Aquaculture Reports 26, 101316'}
      dct:license: CC-BY-4.0
  - name: feed-prices
    title: Feed Prices
    description: Monthly feed prices.
    path: inputs/feed_prices.csv
    prov:generatedAtTime: '2026-01-03'
    prov:wasGeneratedBy: {dct:type: manual-download}
    source:
      dcat:downloadURL: https://example.org/feed.csv
      title: Feed price series
      dct:publisher: *pub
      dct:issued: '2025'
      dct:modified: '2025-06-01'
      dct:license: CC-BY-4.0
