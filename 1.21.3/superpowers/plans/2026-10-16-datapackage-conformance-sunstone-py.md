# Datapackage Conformance (sunstone-py, C1–C9) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every key in `datasets.yaml`, `datasets.lock.yaml` and generated `datapackage.json` is a DP 2.0 property, a sunstone config key, or an RDF property from a known vocabulary; old keys are normalized on read, rewritten by `sunstone migrate`, and agents find terms with `sunstone vocab search`.

**Architecture:** A data layer (`sunstone/vocab/*.json`, generated by `scripts/sync_vocab.py`) feeds a rule registry (`rules.py`) and a validator (`conformance.py`) that walk plain dicts. `aliases.py` renames old keys to new keys in place on ruamel documents (comments kept) and is shared by the `DatasetsManager` read hook, lint and `sunstone migrate`. The write hook (`build_datapackage`, `push_group`) emits new keys as expanded IRIs and validates the descriptor. Lint, vocab search and the schema generator are thin consumers of the same data.

**Tech Stack:** Python 3.12, ruamel.yaml (round-trip), typer, frictionless 5, pint; rdflib only in the `vocab` dependency group for the sync script.

**Spec:** `docs/superpowers/specs/2026-10-15-datapackage-conformance-design.md` (read it first; it is the source of truth).

## Spec conflicts

Each conflict names the spec text, what the code does today, and the resolution this plan uses.

- **SC1. Skill location.** Resolved: the skill is at `claude-plugins/plugins/sunstone-core/skills/dataset/` on `origin/main` (the local checkout was 25 commits behind). Plan 2 must start from an up-to-date `origin/main`.
- **SC2. In-memory normalization rewrites `datasets.yaml` on the next save.** Spec C4 normalizes aliases in `_load` ("one model for the rest of the code"). `DatasetsManager._save()` dumps `self._data`, so any write (`add_output_dataset`, `set_dataset_strict`, `_ensure_min_version`) writes the new key form. Resolution: accept it. The normalizer is ruamel-aware and keeps comments and order, so a save after load produces exactly what `sunstone migrate` would. Document in CHANGELOG. The spec's MUST (new-form files set `min_sunstone_version >= 1.20.0`) is enforced by `aliases.ensure_min_version`, called from `_save()` and `sunstone migrate`, and checked by rule R306. Versions >= 1.8.0 then refuse the file with their existing "requires sunstone-py >= 1.20.0" error.
- **SC3. Lock-file keys are neither DP, config, nor RDF.** The config-key list in the spec covers `datasets.yaml` only. Lock entries use `slug`, `file_hash`, `data_hash`, `created_at`, `sources`, `activity`, `field_derivations`, `context`, `transformation_params`, `fields`. Resolution: `vocab/dp.json` carries a `lock` key list per lock level (`entry`, `source`); the extras rule checks lock entries and lock sources against it. Deeper lock structures (`activity`, `field_derivations`) are machine-written and not key-checked.
- **SC4. Dataset-level `source:` block.** Not in the spec's config list, not DP (DP has `sources`, a list), not RDF. Resolution: `source` is a dataset-level config key (it maps to DP `sources[0]` on emission).
- **SC5. Package-level `license`.** The alias table covers dataset `license` → `licenses` only, but `package.license` and `packages[].license` would fail the extras rule. Resolution: alias `license` → `licenses` (DP list form) at package level too, same transform. `datapackage.json` keeps emitting `license` (existing key) and adds `licenses`.
- **SC6. Keys emitted today that are not DP 2.0.** Resolved by the spec's C5 dual-emission table: package `license` + `licenses`, field `unit` + `si:unit` IRI (+ `qudt:hasUnit`), field `source` + `si:sourceField` IRI, package `vocab#methodology` + `data#methodology`. The table's "resource `license`" row is the package-level `license` key (no resource-level `license` is emitted today; see `_package_metadata_to_dict`). Mechanism: `dp.json` has a `legacy_emitted` allowlist per level, honoured in `datapackage` scope only while `ENFORCE_MUST` is False.
- **SC13. Resource `scheme` is emitted by frictionless and is not in the C5 table.** `build_resource_dict` copies `scheme` (e.g. `file`) from frictionless; it is not a DP 2.0 resource property. Proposed resolution: keep it in `legacy_emitted` for 1.x and strip it in 2.0 together with the C5 left column; add a "resource `scheme` | (none; 2.0 strips it)" row to the spec table.
- **SC14. Two small additions the spec does not list.** (a) The C2 category list has no home for the Methodology rules; the plan adds `Category.METHODOLOGY`. (b) C9's source order omits `sosa`; the plan sorts it after `qudt`, before `si`. Both are proposed spec edits, not design changes.
- **SC7. R102 severity.** The spec makes source `title`, `dcat:downloadURL`/`dcat:landingPage`, `prov:wasAttributedTo`, `dct:license` MUST (lint error). R102 ("source block missing required keys") is a WARNING today. Resolution: R102 keeps its ID and becomes MUST (error) with the new key list. R101 (no source block at all) stays SHOULD.
- **SC8. `Source.acquired_at`, `acquisition_method`, `license` are required `str`.** In the new form they come from the dataset (`prov:generatedAtTime`, `prov:wasGeneratedBy.dct:type`) and may be absent (R312/R102 report it). Resolution: the three become `Optional[str]` with no default (field order unchanged, keyword construction unchanged).
- **SC9. YAML dates.** ruamel loads `acquiredAt: 2025-10-08` as `datetime.date`; once hoisted to `prov:generatedAtTime` it reaches `json.dumps` in `datapackage.json`. Resolution: the normalizer stringifies `date`/`datetime` values of `prov:generatedAtTime` and `dct:modified` (`isoformat()`), and `expand_custom_properties` converts any remaining `date`/`datetime` value the same way.
- **SC11.** Resolved: the spec now uses `dct:type` on the `prov:wasGeneratedBy` activity node.
- **SC12. R102 and R104 severities.** Spec makes source MUST keys and kebab-case `name` MUST (lint error); both rules are warnings today. They keep their IDs and become errors.
- **SC15. `Source.publisher` and `Source.creator` are `Optional[str]` today.** The spec's "Source references" makes `dct:publisher` an agent object and `dct:creator` a list of them. Resolution: new dataclass `lineage.SourceAgent(label, alt_label=None, id=None)`; `Source.publisher: Optional[SourceAgent]`, `Source.creator: Optional[list[SourceAgent]]` (same positions, type change only; nothing in `src/` reads them except `_parse_source` and `_source_entry`). `Source` gains `id`, `issued`, `is_part_of`, `bibliographic_citation` with `None` defaults, appended after `creator`.
- **SC16. String-valued `dct:publisher` / `dct:creator`.** Twelve org sources write `dct:publisher: <free text>` today, and the old fixtures in this plan did too. The spec now requires an agent object with `rdfs:label`, and C7 lists only the DOI move and `attributedTo` as mechanical migrations. Proposed spec addition (C7): `sunstone migrate` wraps a string `dct:publisher` into `{rdfs:label: <string>}` and a string or list-of-strings `dct:creator` into `[{rdfs:label: <string>}, ...]`. No text is split, so it is mechanical. Task 2 implements it in `normalize_document` and reports it as `Rename(path, "dct:publisher", "dct:publisher.rdfs:label")` (R304 on read, like any alias). Every fixture in this plan writes agents as objects.
- **SC17. YAML anchors for repeated agents.** The spec relies on ruamel keeping `&fao` / `*fao` across round-trip and on aliases loading as the same object. The coordinator verified both. Consequence for the normalizer: a shared agent object is visited once per use, and since nothing inside an agent object is renamed, repeated visits are harmless. Task 2 and Task 8 pin anchors with tests. Anchors never cross include files; `DatasetsManager._merge_includes` already loads each include separately, so nothing to do there.
- **SC10. Sync needs network and a `rdf-registry` checkout.** Task 1 downloads eight vocabularies and reads two Turtle files from `~/git/sunstone/rdf-registry`, which must be at an `origin/main` that already contains C11 (`dcat-si:methodology` in `rdf/data.ttl`; plan `2026-10-16-datapackage-conformance-rdf-registry.md`). If a download fails, the checkout is missing, or `dcat-si.json` lacks `methodology`, the task stops and reports; it does not hand-write vocabulary JSON.

## Global Constraints

- Semantic versioning; this plan is the 1.20.0 minor release scope. `ENFORCE_MUST = False`. `pyproject.toml` stays at `1.19.0` until `/release` bumps it; the version gate in `DatasetsManager._load` treats the checkout as at least `1.20.0` (Task 4).
- MUST / MUST NOT violations: one `FutureWarning` per loaded file on read/write (count, first five with paths, "run `sunstone lint` for all of them; these become errors in sunstone-py 2.0"), plus one `FutureWarning` per file with alias keys naming `sunstone migrate`; lint error. SHOULD: lint warning. MAY: not checked. `DeprecationWarning` is never used for conformance (Python hides it inside libraries); it stays for deprecated Python APIs only. `pyproject.toml` has no `filterwarnings`, so a `FutureWarning` stays a warning in the test suite.
- Existing lint IDs R001–R202 keep their numbers. New rules use R3xx.
- Paths written to files use `path.as_posix()` (Windows CI).
- Run tests with `uv run pytest --no-cov` (add `-q`). Before each commit: `uv run ruff check src/sunstone && uv run ruff format src/sunstone tests scripts && uv run --extra polars mypy src/sunstone`.
- Runtime never fetches vocabularies; `rdflib` lives in the `vocab` dependency group only.
- CHANGELOG entries: one short line each, under `## [Unreleased]`, categories Added/Changed/Deprecated/Removed/Fixed.
- Commit messages: conventional prefix (`feat:`, `refactor:`, `test:`, `docs:`), no Co-authored-by lines.
- Never remove or change an existing `datapackage.json` key; add new ones alongside (spec C5 table).
- A `datasets.yaml` in new form sets `min_sunstone_version` to `1.20.0` or higher (`aliases.MIN_NEW_FORM_VERSION`); every write path raises it, rule R306 checks it.
- Shipped vocabularies: `si`, `dcat-si`, `dct`, `dcat`, `prov`, `schema`, `qudt`, `rdfs`, `skos`, `sosa`.
- Source MUST keys (spec "Provenance"): `title`; `dct:publisher` object with `rdfs:label`; a link (`"@id"`, `dcat:downloadURL` or `dcat:landingPage`); `dct:license`. `prov:wasAttributedTo` is MAY. A `doi.org` URL in `dcat:downloadURL` / `dcat:landingPage` is MUST NOT (it goes in `"@id"`).
- Agent object (spec "Source references"): `rdfs:label` (full name), optional `skos:altLabel` (short name), optional `"@id"`. Repeated agents use YAML anchors (`&fao` / `*fao`) within one file; never a lookup table.
- Do not widen scope: no refactors outside the files each task names.

- [ ] **Step 5: Write the loader `src/sunstone/vocab/__init__.py`**

```python
"""Shipped vocabulary data: DP 2.0 property sets, config keys and RDF terms.

All data is read from the JSON files next to this module. Nothing here
touches the network; ``scripts/sync_vocab.py`` regenerates the RDF files.
"""

from __future__ import annotations

import json
from dataclasses import dataclass
from functools import lru_cache
from pathlib import Path
from typing import Any

_DIR = Path(__file__).parent

SHIPPED_VOCABS: tuple[str, ...] = ("dct", "dcat", "prov", "schema", "skos", "rdfs", "qudt", "sosa", "si", "dcat-si")
"""Vocabularies whose terms are checked for existence (spec: Extras MUST)."""

# YAML level -> DP profile level used for key lookup.
_DP_LEVEL_ALIAS = {"dataset": "resource"}


@dataclass(frozen=True)
class Term:
    curie: str
    iri: str
    label: str
    definition: str
    source: str
    """Vocabulary prefix, or ``"dp"`` / ``"config"`` for descriptor keys."""
    levels: tuple[str, ...] = ()
    """Levels where a DP/config key is allowed; empty for RDF terms (allowed anywhere)."""


@lru_cache(maxsize=None)
def _dp() -> dict[str, Any]:
    with open(_DIR / "dp.json", encoding="utf-8") as f:
        return json.load(f)


@lru_cache(maxsize=None)
def aliases() -> dict[str, list[dict[str, str]]]:
    with open(_DIR / "aliases.json", encoding="utf-8") as f:
        return json.load(f)


DP_PROFILE_URL: str = _dp()["profile"]


@lru_cache(maxsize=None)
def load_vocab(prefix: str) -> dict[str, Any]:
    if prefix not in SHIPPED_VOCABS:
        raise KeyError(prefix)
    with open(_DIR / f"{prefix}.json", encoding="utf-8") as f:
        return json.load(f)


@lru_cache(maxsize=None)
def _locals(prefix: str) -> frozenset[str]:
    ns = load_vocab(prefix)["namespace"]
    return frozenset(t["iri"][len(ns) :] for t in load_vocab(prefix)["terms"])


def namespace_of(prefix: str) -> str:
    return str(load_vocab(prefix)["namespace"])


def term_exists(prefix: str, local: str) -> bool:
    return prefix in SHIPPED_VOCABS and local in _locals(prefix)


def dp_keys(level: str) -> frozenset[str]:
    return frozenset(_dp()["dp"].get(_DP_LEVEL_ALIAS.get(level, level), {}))


def config_keys(level: str) -> frozenset[str]:
    return frozenset(_dp()["config"].get(level, {}))


def lock_keys(level: str) -> frozenset[str]:
    return frozenset(_dp()["lock"].get(level, []))


def legacy_emitted_keys(level: str) -> frozenset[str]:
    return frozenset(_dp()["legacy_emitted"].get(_DP_LEVEL_ALIAS.get(level, level), []))


def recommended_keys(level: str) -> dict[str, str]:
    """Spec "Recommended properties": key -> "SHOULD" or "MAY" at this level."""
    return dict(_dp()["recommended"].get(level, {}))


def duplicate_keys(level: str) -> dict[str, str]:
    """Spec "Duplicate properties" (MUST NOT): key -> what to use instead. ``output`` adds to ``dataset``."""
    return dict(_dp()["duplicates"].get(level, {}))


def key_definition(level: str, key: str) -> str:
    dp_level = _DP_LEVEL_ALIAS.get(level, level)
    return str(_dp()["dp"].get(dp_level, {}).get(key) or _dp()["config"].get(level, {}).get(key) or "")


def level_children(level: str) -> dict[str, str]:
    return dict(_dp()["children"].get(level, {}))


def level_for_path(path: str) -> str | None:
    """Resolve a dotted ``datasets.yaml`` path (no array markers) to a level name."""
    level = "document"
    for part in [p for p in path.strip().strip(".").split(".") if p]:
        child = level_children(level).get(part)
        if child is None:
            return None
        level = child
    return level


@lru_cache(maxsize=None)
def all_terms() -> list[Term]:
    terms: list[Term] = []
    dp = _dp()
    by_key: dict[tuple[str, str], list[str]] = {}
    for kind in ("dp", "config"):
        for level, keys in dp[kind].items():
            for key, definition in keys.items():
                by_key.setdefault((kind, key), []).append(level)
    for (kind, key), levels in sorted(by_key.items()):
        definition = next((dp[kind][lvl][key] for lvl in levels if dp[kind][lvl].get(key)), "")
        terms.append(Term(curie=key, iri="", label=key, definition=definition, source=kind, levels=tuple(levels)))
    for prefix in SHIPPED_VOCABS:
        for t in load_vocab(prefix)["terms"]:
            terms.append(
                Term(curie=t["curie"], iri=t["iri"], label=t.get("label", ""), definition=t.get("definition", ""), source=prefix)
            )
    return terms
```

- [ ] **Step 6: Write `scripts/sync_vocab.py`**

```python
"""Regenerate src/sunstone/vocab/<prefix>.json from upstream vocabularies.

Usage:
    uv run --group vocab python scripts/sync_vocab.py [--rdf-registry PATH] [--only PREFIX ...]

Upstream files are pinned below. ``si`` and ``dcat-si`` are read from a local
rdf-registry checkout (default: ~/git/sunstone/rdf-registry).
"""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

import rdflib
from rdflib import OWL, RDF, RDFS, SKOS, DCTERMS, Namespace, URIRef

OUT_DIR = Path(__file__).resolve().parent.parent / "src" / "sunstone" / "vocab"

# prefix -> (namespace recorded in JSON, source, rdflib format, extra namespace spellings accepted in the file)
SOURCES: dict[str, tuple[str, str, str, tuple[str, ...]]] = {
    "dct": ("http://purl.org/dc/terms/", "https://www.dublincore.org/specifications/dublin-core/dcmi-terms/dublin_core_terms.ttl", "turtle", ()),
    "dcat": ("http://www.w3.org/ns/dcat#", "https://www.w3.org/ns/dcat.ttl", "turtle", ()),
    "prov": ("http://www.w3.org/ns/prov#", "https://www.w3.org/ns/prov-o.ttl", "turtle", ()),
    "schema": ("http://schema.org/", "https://schema.org/version/latest/schemaorg-current-https.ttl", "turtle", ("https://schema.org/",)),
    "skos": ("http://www.w3.org/2004/02/skos/core#", "https://www.w3.org/2009/08/skos-reference/skos.rdf", "xml", ()),
    "rdfs": ("http://www.w3.org/2000/01/rdf-schema#", "https://www.w3.org/2000/01/rdf-schema.ttl", "turtle", ()),
    "qudt": ("http://qudt.org/schema/qudt/", "https://qudt.org/3.1.4/schema/qudt.ttl", "turtle", ()),
    "sosa": ("http://www.w3.org/ns/sosa/", "https://www.w3.org/ns/sosa/sosa.ttl", "turtle", ()),
    "si": ("https://sunstone.institute/rdf/vocab#", "rdf/vocab.ttl", "turtle", ()),
    "dcat-si": ("https://sunstone.institute/rdf/data#", "rdf/data.ttl", "turtle", ()),
}

PROPERTY_TYPES = {RDF.Property, OWL.ObjectProperty, OWL.DatatypeProperty, OWL.AnnotationProperty, OWL.FunctionalProperty}
LABEL_PREDICATES = (RDFS.label, DCTERMS.title, SKOS.prefLabel)
DEFINITION_PREDICATES = (RDFS.comment, SKOS.definition, DCTERMS.description)


def _first_literal(g: rdflib.Graph, s: URIRef, predicates: tuple) -> str:
    for p in predicates:
        values = [o for o in g.objects(s, p) if isinstance(o, rdflib.Literal)]
        if not values:
            continue
        english = [v for v in values if (v.language or "en").startswith("en")]
        chosen = english[0] if english else values[0]
        return " ".join(str(chosen).split())
    return ""


def build(prefix: str, registry: Path) -> dict:
    namespace, source, fmt, extra_ns = SOURCES[prefix]
    location = str(registry / source) if not source.startswith("http") else source
    g = rdflib.Graph()
    g.parse(location, format=fmt)
    accepted = (namespace,) + extra_ns
    terms: dict[str, dict] = {}
    for s in set(g.subjects(RDF.type, None)):
        if not isinstance(s, URIRef):
            continue
        if not any(t in PROPERTY_TYPES for t in g.objects(s, RDF.type)):
            continue
        iri = str(s)
        ns_hit = next((ns for ns in accepted if iri.startswith(ns)), None)
        if ns_hit is None:
            continue
        local = iri[len(ns_hit) :]
        if not local or "/" in local or "#" in local:
            continue
        terms[local] = {
            "curie": f"{prefix}:{local}",
            "iri": namespace + local,
            "label": _first_literal(g, s, LABEL_PREDICATES),
            "definition": _first_literal(g, s, DEFINITION_PREDICATES),
        }
    return {
        "prefix": prefix,
        "namespace": namespace,
        "source": source,
        "terms": [terms[k] for k in sorted(terms)],
    }


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--rdf-registry", default=str(Path.home() / "git" / "sunstone" / "rdf-registry"))
    ap.add_argument("--only", nargs="*", default=None)
    args = ap.parse_args()
    registry = Path(args.rdf_registry)
    for prefix in args.only or SOURCES:
        data = build(prefix, registry)
        if not data["terms"]:
            print(f"error: no properties found for {prefix}", file=sys.stderr)
            return 1
        out = OUT_DIR / f"{prefix}.json"
        out.write_text(json.dumps(data, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")
        print(f"{prefix}: {len(data['terms'])} terms -> {out.relative_to(OUT_DIR.parent.parent.parent)}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
"""Rename old datasets.yaml / lock keys to their DP 2.0 or RDF names, in place.

Works on plain dicts and on ruamel ``CommentedMap`` objects (comments and key
order kept). Used by ``DatasetsManager._load``, lint and ``sunstone migrate``.
"""

from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date, datetime
from typing import Any, Literal, Mapping, MutableMapping

from ruamel.yaml import YAML
from ruamel.yaml.comments import CommentedMap, CommentedSeq


def make_yaml() -> YAML:
    yaml = YAML()
    yaml.preserve_quotes = True
    yaml.default_flow_style = False
    yaml.width = 4096
    yaml.indent(mapping=2, sequence=4, offset=2)
    return yaml


@dataclass(frozen=True)
class Rename:
    path: str
    old: str
    new: str


@dataclass
class NormalizeResult:
    renames: list[Rename] = field(default_factory=list)
    ambiguous: list[str] = field(default_factory=list)
    new_form: bool = False
    """True when the input already used a new-form key (before renaming)."""


MIN_NEW_FORM_VERSION = "1.20.0"
"""First sunstone-py version that reads the new key form (spec: Extras MUST)."""

Form = Literal["old", "new", "ambiguous", "untitled"]

_NEW_FORM_DATASET_KEYS = frozenset({"path", "schema", "licenses", "prov:generatedAtTime", "prov:wasGeneratedBy"})
_NEW_FORM_SOURCE_KEYS = frozenset(
    {"prov:wasAttributedTo", "dct:license", "dct:modified", "dcat:downloadURL", "dcat:landingPage", "dcat:accessURL", "rdfs:seeAlso",
     "@id", "dct:issued", "dct:isPartOf", "dct:bibliographicCitation"}
)

_DOI_PREFIXES = ("https://doi.org/", "http://doi.org/", "https://dx.doi.org/", "http://dx.doi.org/")


def is_doi_url(value: str) -> bool:
    """True for a resolvable DOI URL (spec: a DOI goes in ``"@id"``, never in a DCAT link)."""
    return value.startswith(_DOI_PREFIXES)
_NEW_FORM_FIELD_KEYS = frozenset({"si:unit", "si:sourceField", "qudt:hasUnit"})


def uses_new_form(data: Mapping[str, Any]) -> bool:
    """True when any new-form key is present. Call before normalizing."""
    if "dcat-si:methodology" in data:
        return True
    for section in ("inputs", "outputs"):
        for entry in data.get(section) or []:
            if not isinstance(entry, Mapping):
                continue
            if _NEW_FORM_DATASET_KEYS & set(entry) or ("title" in entry and "slug" not in entry):
                return True
            src = entry.get("source")
            if isinstance(src, Mapping) and _NEW_FORM_SOURCE_KEYS & set(src):
                return True
            schema = entry.get("schema")
            fields = schema.get("fields") if isinstance(schema, Mapping) else entry.get("fields")
            for fld in fields or []:
                if isinstance(fld, Mapping) and _NEW_FORM_FIELD_KEYS & set(fld):
                    return True
    for pkg in [data.get("package"), *(data.get("packages") or [])]:
        if isinstance(pkg, Mapping) and "licenses" in pkg:
            return True
    return False


def version_key(v: str) -> tuple[int, ...]:
    parts = []
    for p in str(v).split("."):
        digits = "".join(ch for ch in p if ch.isdigit())
        parts.append(int(digits) if digits else 0)
    return tuple(parts)


def ensure_min_version(data: MutableMapping[str, Any], required: str = MIN_NEW_FORM_VERSION) -> bool:
    """Insert or raise ``min_sunstone_version``; never lowers it. Returns True when the document changed."""
    current = data.get("min_sunstone_version")
    if current is not None and version_key(str(current)) >= version_key(required):
        return False
    if "min_sunstone_version" in data:
        data["min_sunstone_version"] = required
    else:
        _insert(data, 0, "min_sunstone_version", required)
    return True


def detect_form(entry: Mapping[str, Any]) -> Form:
    has_slug, has_title = "slug" in entry, "title" in entry
    if has_slug and has_title:
        return "ambiguous"
    if has_slug:
        return "old"
    if has_title:
        return "new"
    return "untitled"


def _new_map() -> MutableMapping[str, Any]:
    return CommentedMap()


def _new_seq() -> list:
    return CommentedSeq()


def _insert(m: MutableMapping[str, Any], idx: int, key: str, value: Any) -> None:
    if isinstance(m, CommentedMap):
        m.insert(idx, key, value)
        return
    items = list(m.items())
    m.clear()
    for i, (k, v) in enumerate(items):
        if i == idx:
            m[key] = value
        m[k] = v
    if key not in m:
        m[key] = value


def _move_comment(m: MutableMapping[str, Any], old: str, new: str) -> None:
    ca = getattr(m, "ca", None)
    if ca is None:
        return
    item = ca.items.pop(old, None)
    if item is not None:
        ca.items[new] = item


def rename_key(m: MutableMapping[str, Any], old: str, new: str, path: str, result: NormalizeResult) -> None:
    """Rename ``old`` to ``new`` keeping position and comment. Drops ``old`` when ``new`` exists."""
    if old not in m:
        return
    value = m[old]
    idx = list(m.keys()).index(old)
    if new in m:
        del m[old]
    else:
        _insert(m, idx, new, value)
        del m[old]
        _move_comment(m, old, new)
    result.renames.append(Rename(path, old, new))


def _set_at(m: MutableMapping[str, Any], idx: int, key: str, value: Any) -> None:
    if key in m:
        return
    _insert(m, idx, key, value)


def _iso(value: Any) -> Any:
    if isinstance(value, (date, datetime)):
        return value.isoformat()
    return value


def _license_list(value: Any) -> Any:
    if isinstance(value, list) or value is None:
        return value
    seq = _new_seq()
    entry = _new_map()
    entry["name"] = value
    seq.append(entry)
    return seq


_LOCATION_KEYS = (
    ("data", "dcat:downloadURL"),
    ("dcat:downloadURL", "dcat:downloadURL"),
    ("about", "dcat:landingPage"),
    ("dcat:landingPage", "dcat:landingPage"),
    ("web", "dcat:landingPage"),
    ("metadata", "rdfs:seeAlso"),
    ("access", "dcat:accessURL"),
    ("dcat:accessURL", "dcat:accessURL"),
)


def _normalize_source(src: MutableMapping[str, Any], path: str, result: NormalizeResult) -> tuple[Any, Any]:
    """Normalize a source block. Returns (acquired_at, acquisition_method) popped from it."""
    rename_key(src, "name", "title", path, result)
    rename_key(src, "license", "dct:license", path, result)
    rename_key(src, "updated", "dct:modified", path, result)
    if "dct:modified" in src:
        src["dct:modified"] = _iso(src["dct:modified"])

    if "attributedTo" in src:
        raw = src["attributedTo"]
        idx = list(src.keys()).index("attributedTo")
        if isinstance(raw, Mapping):
            node = _new_map()
            if "id" in raw:
                node["@id"] = raw["id"]
            if "type" in raw:
                node["@type"] = raw["type"]
            if raw.get("label"):
                node["rdfs:label"] = raw["label"]
            del src["attributedTo"]
            _set_at(src, idx, "prov:wasAttributedTo", node)
            if raw.get("version") is not None:
                _set_at(src, idx + 1, "version", raw["version"])
                result.renames.append(Rename(path, "attributedTo.version", "version"))
            result.renames.append(Rename(path, "attributedTo", "prov:wasAttributedTo"))
        else:
            rename_key(src, "attributedTo", "prov:wasAttributedTo", path, result)

    # Agent objects (SC16): a string publisher / creator becomes {rdfs:label: <string>}; nothing is split.
    if isinstance(src.get("dct:publisher"), str):
        node = _new_map()
        node["rdfs:label"] = src["dct:publisher"]
        src["dct:publisher"] = node  # same key, same position
        result.renames.append(Rename(path, "dct:publisher", "dct:publisher.rdfs:label"))
    creator = src.get("dct:creator")
    if isinstance(creator, str) or (isinstance(creator, list) and any(isinstance(c, str) for c in creator)):
        seq = _new_seq()
        for c in [creator] if isinstance(creator, str) else creator:
            if isinstance(c, str):
                node = _new_map()
                node["rdfs:label"] = c
                seq.append(node)
            else:
                seq.append(c)
        src["dct:creator"] = seq
        result.renames.append(Rename(path, "dct:creator", "dct:creator[].rdfs:label"))

    loc = src.get("location")
    if isinstance(loc, MutableMapping):
        # DOI move (spec C7): a doi.org URL is an identifier, not a link.
        for old in ("data", "web", "about"):
            value = loc.get(old)
            if isinstance(value, str) and is_doi_url(value):
                del loc[old]
                if "@id" not in src:
                    _insert(src, 0, "@id", value)
                result.renames.append(Rename(f"{path}.location", old, "@id"))
        idx = list(src.keys()).index("location")
        for old, new in _LOCATION_KEYS:
            if old in loc:
                value = loc.pop(old)
                if new not in src:
                    _insert(src, idx, new, value)
                    idx += 1
                result.renames.append(Rename(f"{path}.location", old, new))
        if not loc:
            del src["location"]

    acquired_at = src.pop("acquiredAt", None)
    if acquired_at is not None:
        result.renames.append(Rename(path, "acquiredAt", "prov:generatedAtTime"))
    method = src.pop("acquisitionMethod", None)
    if method is not None:
        result.renames.append(Rename(path, "acquisitionMethod", "prov:wasGeneratedBy"))
    return acquired_at, method


def _normalize_field(fld: MutableMapping[str, Any], path: str, result: NormalizeResult) -> None:
    if "unit" in fld:
        from .units import is_qudt_uri, parse_unit_string

        raw = fld["unit"]
        rename_key(fld, "unit", "si:unit", path, result)
        if isinstance(raw, str) and is_qudt_uri(raw):
            try:
                pint_unit, _ = parse_unit_string(raw)
                fld["si:unit"] = str(pint_unit)
            except Exception:
                fld["si:unit"] = raw
            if "qudt:hasUnit" not in fld:
                _insert(fld, list(fld.keys()).index("si:unit") + 1, "qudt:hasUnit", raw)
    rename_key(fld, "source", "si:sourceField", path, result)
    rename_key(fld, "dct:title", "title", path, result)


def _normalize_dataset(entry: MutableMapping[str, Any], path: str, result: NormalizeResult) -> None:
    form = detect_form(entry)
    if form == "ambiguous":
        result.ambiguous.append(path)
    elif form == "old":
        rename_key(entry, "name", "title", path, result)
        rename_key(entry, "slug", "name", path, result)
    rename_key(entry, "location", "path", path, result)
    if "license" in entry:
        entry["license"] = _license_list(entry["license"])
        rename_key(entry, "license", "licenses", path, result)

    for old in ("fields", "primaryKey"):
        if old in entry:
            value = entry[old]
            idx = list(entry.keys()).index(old)
            schema = entry.get("schema")
            if not isinstance(schema, MutableMapping):
                schema = _new_map()
                _insert(entry, idx, "schema", schema)
            if old not in schema:
                schema[old] = value
            del entry[old]
            result.renames.append(Rename(path, old, f"schema.{old}"))

    acquired_at = method = None
    src = entry.get("source")
    if isinstance(src, MutableMapping):
        acquired_at, method = _normalize_source(src, f"{path}.source", result)
        idx = list(entry.keys()).index("source") + 1
        if acquired_at is not None and "prov:generatedAtTime" not in entry:
            _insert(entry, idx, "prov:generatedAtTime", _iso(acquired_at))
            idx += 1
        if method is not None and "prov:wasGeneratedBy" not in entry:
            node = _new_map()
            node["@type"] = "prov:Activity"
            node["dct:type"] = method
            _insert(entry, idx, "prov:wasGeneratedBy", node)
    if "prov:generatedAtTime" in entry:
        entry["prov:generatedAtTime"] = _iso(entry["prov:generatedAtTime"])

    schema = entry.get("schema")
    if isinstance(schema, Mapping):
        fields = schema.get("fields")
        if isinstance(fields, list):
            for i, fld in enumerate(fields):
                if isinstance(fld, MutableMapping):
                    _normalize_field(fld, f"{path}.schema.fields[{i}]", result)


def _normalize_package(pkg: MutableMapping[str, Any], path: str, result: NormalizeResult) -> None:
    if "license" in pkg:
        pkg["license"] = _license_list(pkg["license"])
        rename_key(pkg, "license", "licenses", path, result)


def normalize_document(data: MutableMapping[str, Any]) -> NormalizeResult:
    result = NormalizeResult(new_form=uses_new_form(data))
    rename_key(data, "si:methodology", "dcat-si:methodology", "", result)
    for section in ("inputs", "outputs"):
        items = data.get(section)
        if isinstance(items, list):
            for i, entry in enumerate(items):
                if isinstance(entry, MutableMapping):
                    _normalize_dataset(entry, f"{section}[{i}]", result)
    pkg = data.get("package")
    if isinstance(pkg, MutableMapping):
        _normalize_package(pkg, "package", result)
    pkgs = data.get("packages")
    if isinstance(pkgs, list):
        for i, pkg in enumerate(pkgs):
            if isinstance(pkg, MutableMapping):
                _normalize_package(pkg, f"packages[{i}]", result)
    return result


def normalize_lock(lock: MutableMapping[str, Any]) -> NormalizeResult:
    result = NormalizeResult()
    for section in ("inputs", "outputs"):
        for i, entry in enumerate(lock.get(section) or []):
            if not isinstance(entry, MutableMapping):
                continue
            for j, src in enumerate(entry.get("sources") or []):
                if isinstance(src, MutableMapping):
                    p = f"{section}[{i}].sources[{j}]"
                    rename_key(src, "attributedTo", "prov:wasAttributedTo", p, result)
                    rename_key(src, "license", "dct:license", p, result)
    return result
```

```python
        if rule.deprecation and not enforce_must:

        return Severity.ERROR
    if rule.level is Level.SHOULD:

    return Severity.INFO
```

```python
        for section in ("inputs", "outputs"):
            for entry in self.lock.get(section) or []:
                if isinstance(entry, Mapping) and entry.get("slug") == name:

                        if isinstance(fld, Mapping) and fld.get("name") and (fld.get("unit") or fld.get("si:unit")):

def _check_key(ctx: ConformanceContext, key: str, level: str, path: str) -> Iterator[Violation]:
    kpath = f"{path}.{key}" if path else key
    if key in ("@id", "@type"):
        return
    if ctx.kind == "yaml" and key in config_keys(level):
        return
    if ctx.kind == "lock":
        if key in lock_keys(level):
            return
    elif level != "node" and key in dp_keys(level):
        return
    if ctx.kind == "datapackage" and not ENFORCE_MUST and key in legacy_emitted_keys(level):
        return
    if key.startswith(("http://", "https://")):
        for prefix in SHIPPED_VOCABS:
            ns = namespace_of(prefix)
            if key.startswith(ns):
                local = key[len(ns) :]
                if not term_exists(prefix, local):
                    yield ctx.violation("R303", kpath, f"'{prefix}:{local}' is not a term in the {prefix} vocabulary")
                return
        return
    if ":" in key:
        prefix, local = key.split(":", 1)
        if prefix not in ctx.prefixes:
            yield ctx.violation("R302", kpath, f"prefix '{prefix}' is not declared")
        elif prefix in SHIPPED_VOCABS and not term_exists(prefix, local):
            yield ctx.violation("R303", kpath, f"'{key}' is not a term in the {prefix} vocabulary")
        return
    at = _ARRAY_RE.sub("", path)
    yield ctx.violation(
        "R301",
        kpath,
        f"unknown key '{key}' at level '{level}'",
        f'Run `sunstone vocab search "{split_camel(key)}" --at {at or "."}` and use a listed key.',
    )


def _walk(ctx: ConformanceContext, m: Mapping[str, Any], level: str, path: str) -> Iterator[Violation]:
    children = level_children(level)
    for key, value in m.items():
        if not isinstance(key, str):
            continue
        yield from _check_key(ctx, key, level, path)
        kpath = f"{path}.{key}" if path else key
        child = children.get(key)
        if child is not None:
            if isinstance(value, list):
                for i, item in enumerate(value):
                    if isinstance(item, Mapping):
                        yield from _walk(ctx, item, child, f"{kpath}[{i}]")
            elif isinstance(value, Mapping):
                yield from _walk(ctx, value, child, kpath)
        elif _is_rdf_key(key):
            if isinstance(value, Mapping):
                yield from _walk(ctx, value, "node", kpath)
            elif isinstance(value, list):
                for i, item in enumerate(value):
                    if isinstance(item, Mapping):
                        yield from _walk(ctx, item, "node", f"{kpath}[{i}]")

def run_checks(ctx: ConformanceContext) -> list[Violation]:
    out: list[Violation] = []
    for rule in RULES.values():
        if rule.check is None or not any(s.startswith(ctx.kind + ":") for s in rule.scope):
            continue
        out.extend(rule.check(ctx))
    return out


def _collect_prefixes(data: Mapping[str, Any]) -> dict[str, str]:
    prefixes = dict(STANDARD_RDF_PREFIXES)
    defaults = data.get("defaults")
    for block in (data.get("rdfPrefixes"), defaults.get("rdfPrefixes") if isinstance(defaults, Mapping) else None):
        if isinstance(block, Mapping):
            prefixes.update({str(k): str(v) for k, v in block.items()})
    for section in ("inputs", "outputs"):
        for ds in data.get(section) or []:
            block = ds.get("rdfPrefixes") if isinstance(ds, Mapping) else None
            if isinstance(block, Mapping):
                prefixes.update({str(k): str(v) for k, v in block.items()})
    return prefixes

def validate_datasets_yaml(
    data: Mapping[str, Any],
    *,
    lock: Optional[Mapping[str, Any]] = None,
    field_types: Optional[Any] = None,
    normalize: bool = True,
    result: Any = None,
) -> list[Violation]:
    """Validate a datasets.yaml document.

    With ``normalize=True`` (default) the document is deep-copied and alias
    keys are normalized first; ``data`` is never mutated. Pass
    ``normalize=False`` with the ``NormalizeResult`` from an earlier
    ``normalize_document`` call when the caller already normalized in place.
    """
    if normalize:
        data = copy.deepcopy(data)
        result = normalize_document(data)  # type: ignore[arg-type]
    renames = list(result.renames) if result is not None else []
    ambiguous = list(result.ambiguous) if result is not None else []
    ctx = ConformanceContext(
        kind="yaml",
        data=data,
        lock=lock or {},
        renames=renames,
        ambiguous=ambiguous,
        prefixes=_collect_prefixes(data),
        field_types=frozenset(field_types) if field_types is not None else _default_field_types(),
        new_form=bool(result.new_form) if result is not None else False,
    )
    return run_checks(ctx)


def validate_lock(
    lock: Mapping[str, Any],
    data: Mapping[str, Any],
    *,
    normalize: bool = True,
    result: Any = None,
) -> list[Violation]:
    """Validate datasets.lock.yaml against the (normalized) datasets.yaml document."""
    if normalize:
        lock = copy.deepcopy(lock)
        result = normalize_lock(lock)  # type: ignore[arg-type]
    ctx = ConformanceContext(
        kind="lock",
        data=data,
        lock=lock,
        renames=list(result.renames) if result is not None else [],
        prefixes=_collect_prefixes(data),
    )
    return run_checks(ctx)

    """Validate a finished datapackage.json descriptor (keys are expanded IRIs)."""
    ctx = ConformanceContext(kind="datapackage", data=descriptor, prefixes=dict(STANDARD_RDF_PREFIXES))

SHOWN_IN_WARNING = 5
"""How many MUST violations the per-file FutureWarning lists (spec C4)."""


def enforce(violations: list[Violation], *, where: str, stacklevel: int = 3) -> None:
    """Apply the release policy to MUST violations: one FutureWarning per file in 1.x, ConformanceError in 2.0.

    FutureWarning, not DeprecationWarning: Python hides DeprecationWarning raised inside a library.
    """
    must = [v for v in violations if v.level in (Level.MUST, Level.MUST_NOT)]
    if not must:
        return
    if ENFORCE_MUST:
        lines = [f"[{v.rule_id}] {v.path}: {v.message}" for v in must]
        raise ConformanceError(f"{where}: " + "; ".join(lines))
    aliases = [v for v in must if v.rule_id == "R304"]
    others = [v for v in must if v.rule_id != "R304"]
    if others:
        shown = "; ".join(f"[{v.rule_id}] {v.path}: {v.message}" for v in others[:SHOWN_IN_WARNING])
        more = f" (+{len(others) - SHOWN_IN_WARNING} more)" if len(others) > SHOWN_IN_WARNING else ""
        warnings.warn(
            f"{where}: {len(others)} MUST violation(s): {shown}{more}; "
            "run `sunstone lint` for all of them; these become errors in sunstone-py 2.0",
            FutureWarning,
            stacklevel=stacklevel,
        )
    if aliases:
        warnings.warn(
            f"{where}: {len(aliases)} deprecated key(s) (e.g. {aliases[0].path}); run `sunstone migrate`; "
            "these become errors in sunstone-py 2.0",
            FutureWarning,
            stacklevel=stacklevel,
        )
```

```python
    def _parse_source(self, source_data: Dict[str, Any], dataset_data: Dict[str, Any]) -> Source:
        """Parse a normalized source block; acquisition metadata comes from the dataset."""
        raw_agent = source_data.get("prov:wasAttributedTo")
        attributed_to: str | Agent
        if isinstance(raw_agent, dict):
            attributed_to = Agent(
                id=str(raw_agent.get("@id", raw_agent.get("rdfs:label", ""))),

                label=raw_agent.get("rdfs:label"),

            )

        method = generated_by.get("dct:type") if isinstance(generated_by, dict) else None
        acquired = dataset_data.get("prov:generatedAtTime")

        creators = source_data.get("dct:creator")

        citation = source_data.get("dct:bibliographicCitation")
```

```python
    """Spec "Source references" agent object with expanded keys (sunstone-cms#610 reads these IRIs literally)."""
    node: dict[str, Any] = {}
    if agent.id:

def _source_entry(source: Source) -> dict[str, Any]:
    entry: dict[str, Any] = {}
    if source.id:
        entry["@id"] = source.id
    entry["title"] = source.name
    loc = source.location
    path = loc.data or loc.about or loc.metadata or loc.access or source.id  # spec: derived, "@id" is the last fallback
    if path:
        entry["path"] = path
    dcat = STANDARD_RDF_PREFIXES["dcat"]
    for prop, value in (("downloadURL", loc.data), ("accessURL", loc.access), ("landingPage", loc.about)):
        if value:
            entry[f"{dcat}{prop}"] = value
    if loc.metadata:
        entry[f"{_RDFS}seeAlso"] = loc.metadata
    if source.publisher:
        entry[f"{_DCT}publisher"] = _agent_node(source.publisher)
    if source.creator:
        entry[f"{_DCT}creator"] = [_agent_node(a) for a in source.creator]
    if source.issued:
        entry[f"{_DCT}issued"] = source.issued
    if source.is_part_of:
        entry[f"{_DCT}isPartOf"] = _expand_value(source.is_part_of, STANDARD_RDF_PREFIXES)
    if source.bibliographic_citation:
        entry[f"{_DCT}bibliographicCitation"] = source.bibliographic_citation
    agent = source.attributed_to
    if isinstance(agent, Agent):
        node: dict[str, Any] = {"@id": agent.id, "@type": expand_rdf_prefixes(agent.type.value, STANDARD_RDF_PREFIXES)}
        if agent.label:
            node[f"{_RDFS}label"] = agent.label
        entry[f"{_PROV}wasAttributedTo"] = node
        if agent.version:
            entry["version"] = agent.version
    elif agent:
        entry[f"{_PROV}wasAttributedTo"] = str(agent)
    for prop, value in (("license", source.license), ("modified", source.updated)):
        if value:
            entry[f"{_DCT}{prop}"] = value
    return entry
```

```python
def lint_project(
    project_path: Path | str,
    *,
    datasets_file: str = "datasets.yaml",
    rules: set[str] | None = None,
) -> LintReport:
    project = Path(project_path).resolve()
    if project.is_file():
        yaml_path = project
        project = project.parent
    else:
        yaml_path = project / datasets_file

    if not yaml_path.exists():
        return LintReport(project_path=project)

    with open(yaml_path, "r") as f:
        data = _yaml.load(f) or {}
    result = normalize_document(data)

    lock_path = project / "datasets.lock.yaml"
    lock_data: dict[str, Any] = {}
    lock_result = None
    if lock_path.exists():
        with open(lock_path, "r") as f:
            lock_data = _yaml.load(f) or {}
        lock_result = normalize_lock(lock_data)

    from .plugins import PluginRegistry

    field_types = PluginRegistry.get(project).field_types.known()

    report = LintReport(project_path=project)
    suppressions, config_violations = _parse_lint_config(data.get("lint"))
    report.suppressions = suppressions

    enabled = (lambda rid: rules is None or rid in rules)

    # R009 violations are NEVER suppressed — that's how we keep lint.disable honest.
    for v in config_violations:
        if enabled(v.rule_id):
            report.add(v)

    violations = validate_datasets_yaml(data, lock=lock_data, field_types=field_types, normalize=False, result=result)
    if lock_result is not None:
        violations += validate_lock(lock_data, data, normalize=False, result=lock_result)

    for v in violations:
        if not enabled(v.rule_id):
            continue
        if v.rule_id in suppressions:
            report.suppressed.append(v)
        else:
            report.add(v)
    return report
```

```python
"""Linear-scan search over shipped vocabularies and descriptor keys (``sunstone vocab search``)."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Any, Optional

from .conformance import KEY_LEVELS, split_camel
from .rules import Level
from .vocab import Term, all_terms, config_keys, dp_keys, key_definition, level_for_path

SOURCE_ORDER: tuple[str, ...] = ("dp", "config", "dct", "dcat", "prov", "schema", "skos", "rdfs", "qudt", "sosa", "si", "dcat-si")
_RULE_ORDER = {"MUST": 0, "MUST NOT": 0, "SHOULD": 1, "MAY": 2}
_JSONLD_DEFINITIONS = {
    "@id": "JSON-LD identifier of the node. On a source: the DOI as https://doi.org/<doi>, or another persistent IRI.",
    "@type": "JSON-LD type of the node, e.g. prov:Activity.",
}


@dataclass(frozen=True)
class KeyInfo:
    key: str
    cls: str
    level: str
    rule_level: str
    rule_id: Optional[str]
    definition: str


def _match_fields(term: Term) -> tuple[str, str, str, str]:
    local = term.curie.split(":", 1)[1] if term.iri else term.curie
    return (f"{local} {split_camel(local)}".lower(), term.curie.lower(), term.label.lower(), term.definition.lower())


def _tier(word: str, fields: tuple[str, str, str, str]) -> Optional[int]:
    if word in fields[0] or word in fields[1]:
        return 1
    if word in fields[2]:
        return 2
    if word in fields[3]:
        return 3
    return None


def _resolve_level(at: Optional[str]) -> Optional[str]:
    if at is None:
        return None
    level = level_for_path(at)
    if level is None:
        raise ValueError(f"unknown datasets.yaml path: {at!r}")
    return level


def search(query: str, *, at: Optional[str] = None, limit: int = 20) -> list[Term]:
    words = query.lower().split()
    level = _resolve_level(at)
    scored: list[tuple[int, int, str, Term]] = []
    for term in all_terms():
        if level is not None and term.source in ("dp", "config") and level not in term.levels:
            continue
        fields = _match_fields(term)
        tiers = [_tier(w, fields) for w in words]
        if not words or any(t is None for t in tiers):
            continue
        best = min(t for t in tiers if t is not None)
        scored.append((best, SOURCE_ORDER.index(term.source), term.curie, term))
    scored.sort(key=lambda s: s[:3])
    return [s[3] for s in scored[:limit]]


def explain(at: str) -> list[KeyInfo]:
    level = _resolve_level(at)
    assert level is not None
    infos: dict[str, KeyInfo] = {}
    for key in dp_keys(level):
        infos[key] = KeyInfo(key, "dp", level, "MAY", None, key_definition(level, key))
    for key in config_keys(level):
        infos[key] = KeyInfo(key, "config", level, "MAY", None, key_definition(level, key))
    for (lvl, key), (rule_level, rule_id) in KEY_LEVELS.items():
        if lvl != level:
            continue
        existing = infos.get(key)
        cls = existing.cls if existing else ("config" if key in config_keys(level) else "jsonld" if key.startswith("@") else "rdf")
        definition = existing.definition if existing else _JSONLD_DEFINITIONS.get(key) or _rdf_definition(key)
        infos[key] = KeyInfo(key, cls, level, rule_level.value, rule_id, definition)
    return sorted(infos.values(), key=lambda k: (_RULE_ORDER[k.rule_level], k.key))


def _rdf_definition(curie: str) -> str:
    for term in all_terms():
        if term.curie == curie and term.iri:
            return term.definition
    return ""


def term_to_dict(term: Term) -> dict[str, Any]:
    return {
        "curie": term.curie,
        "iri": term.iri,
        "label": term.label,
        "definition": term.definition,
        "source": term.source,
        "levels": list(term.levels),
    }


def key_info_to_dict(info: KeyInfo) -> dict[str, Any]:
    return {"key": info.key, "class": info.cls, "level": info.level, "rule": info.rule_level, "rule_id": info.rule_id, "definition": info.definition}


__all__ = ["KeyInfo", "SOURCE_ORDER", "explain", "key_info_to_dict", "search", "term_to_dict", "Level"]
```

```python
"""``sunstone migrate``: rewrite datasets.yaml, its include files and datasets.lock.yaml to the new key form."""

from __future__ import annotations

import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

from .aliases import NormalizeResult, ensure_min_version, make_yaml, normalize_document, normalize_lock
from .conformance import split_camel, validate_datasets_yaml

LOCK_HEADER = "# Auto-generated by sunstone. Do not edit manually.\n"
_ARRAY_RE = re.compile(r"\[\d+\]")


@dataclass(frozen=True)
class UnknownKey:
    path: str
    key: str
    suggestions: list[str]


@dataclass
class MigrationReport:
    changed: dict[str, int] = field(default_factory=dict)
    unknown: list[UnknownKey] = field(default_factory=list)
    dry_run: bool = False


def _write(path: Path, data: Any, *, header: str = "") -> None:
    yaml = make_yaml()
    ca = getattr(data, "ca", None)
    if header and ca is not None:
        ca.comment = None
    with open(path, "w") as f:
        if header:
            f.write(header)
        yaml.dump(data, f)


def _suggest(key: str, path: str) -> list[str]:
    from .vocab import level_for_path
    from .vocab_search import search

    at = _ARRAY_RE.sub("", path)
    at = at if level_for_path(at) is not None else None
    return [t.curie for t in search(split_camel(key), at=at, limit=3)]


def migrate_project(project_path: Path | str, *, datasets_file: str = "datasets.yaml", dry_run: bool = False) -> MigrationReport:
    project = Path(project_path).resolve()
    main_path = project / datasets_file
    yaml = make_yaml()
    report = MigrationReport(dry_run=dry_run)

    with open(main_path, "r") as f:
        main = yaml.load(f) or {}
    main_result = normalize_document(main)
    main_changes = len(main_result.renames)
    if (main_result.renames or main_result.new_form) and ensure_min_version(main):
        main_changes += 1
    if main_changes:
        report.changed[main_path.name] = main_changes
        if not dry_run:
            _write(main_path, main)

    for rel in main.get("include") or []:
        inc_path = (main_path.parent / str(rel)).resolve()
        if not inc_path.exists():
            continue
        with open(inc_path, "r") as f:
            inc = yaml.load(f) or {}
        inc_result = normalize_document(inc)
        if inc_result.renames:
            report.changed[Path(str(rel)).as_posix()] = len(inc_result.renames)
            if not dry_run:
                _write(inc_path, inc)

    lock_path = main_path.parent / "datasets.lock.yaml"
    if lock_path.exists():
        with open(lock_path, "r") as f:
            lock = yaml.load(f) or {}
        lock_result = normalize_lock(lock)
        if lock_result.renames:
            report.changed[lock_path.name] = len(lock_result.renames)
            if not dry_run:
                _write(lock_path, lock, header=LOCK_HEADER)

    for v in validate_datasets_yaml(main, normalize=False, result=NormalizeResult()):
        if v.rule_id != "R301":
            continue
        container, _, key = v.path.rpartition(".")
        report.unknown.append(UnknownKey(v.path, key, _suggest(key, container)))
    return report
```

```python
def _level_schema(level: str, keys: set[str], defs_available: set[str]) -> dict[str, Any]:
    props: dict[str, Any] = {}
    children = level_children(level)
    for key in sorted(keys):
        child = children.get(key)
        if child in defs_available:
            ref = {"$ref": f"#/definitions/{child}"}
            props[key] = {"type": "array", "items": ref} if key in ARRAY_KEYS else ref
        else:
            props[key] = {}
    out: dict[str, Any] = {"type": "object", "properties": props, "patternProperties": dict(RDF_KEY_PATTERNS), "additionalProperties": False}
    if level == "node":
        out["properties"] = {"@id": {"type": "string"}, "@type": {"type": "string"}}
    return out


def render_datasets_schema() -> dict[str, Any]:
    levels = set(YAML_LEVELS)
    defs = {lvl: _level_schema(lvl, set(dp_keys(lvl)) | set(config_keys(lvl)), levels) for lvl in YAML_LEVELS}
    return {
        "$schema": "http://json-schema.org/draft-07/schema#",
        "$id": SCHEMA_BASE + "datasets.schema.json",
        "title": "sunstone datasets.yaml",
        "description": "Keys are Data Package 2.0 properties, sunstone config keys, or RDF properties (prefix:local or IRI).",

        "definitions": defs,

    from ..rules import RULES
    from ..vocab_search import explain

        "# datasets.yaml key reference",

        "",

        "",

        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_text(text, encoding="utf-8")
    return [p for p, _ in out]
```
